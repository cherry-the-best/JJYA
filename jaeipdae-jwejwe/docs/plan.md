# 계획서 요약

전체 계획서는 Claude Docs에 있고, 여기에는 구현할 때 자주 보는 내용만 옮겨 둔다.
수치는 잠정값이며 data.py와 같은 값을 쓴다.

## 게임 흐름

타이틀 → 군 선택 → 보직 선택 → [아침 → 일과 → 미니게임 또는 행동 → 이벤트 → 저녁 → 집합 판정 → NPC 행동] 반복 → 전역 판정 → 엔딩 도감

공통 미니게임은 암구호 외우기, 군대 상식 퀴즈, 불시 점검이다.

## 사이클과 계급

- 육군과 해병대 18개월 39사이클, 공군 21개월 45사이클
- 계급 구간 3 : 6 : 6 : 3. 이병 0~16.7%, 일병 16.7~50%, 상병 50~83.3%, 병장 83.3~100%
- 해금: 이병 훈련, 심부름 / 일병 PX / 상병 자기계발, 체력단련, 후임 챙기기 / 병장 낮잠, 휴가 계획, 집합 걸기
- 훈련을 2사이클 하면 다른 행동을 1번 고를 수 있다

## 스탯

시작값은 체력 70, 지능 40, 정신력 70, 찍힘도 0이고 보직 보정을 더한다. 모두 0~100이다.
체력 0은 의병전역, 정신력 0은 탈영이고 둘 다 입영통지서 엔딩이다.
선임 집합 확률은 `min(0.9, base(계급) + 0.004 × 찍힘도)`이다.

## 엔딩 판정 순서

1. 극악 확률: 미통령, 전기차 CEO, 대통령 각 0.5%
2. 지능 70 미만이면 입영통지서
3. 부사관 권유를 수락했고 체력 70 이상이면 부사관
4. 군별 히든: 공군 파일럿, 해병대 선장 각 50%와 군별 이벤트 보너스
5. 재미 히든: 원양어선 40%, 도를 믿습니까 40%, 쉬었음 청년 30%
6. 가장 높은 스탯 계열의 일반 직업. 85 이상이면 보직 연결 직업, 미만이면 계열 공통 직업 4개 중 하나

## 처음 돌려 본 밸런스

`python tests/simulate.py 100`으로 무작위 행동을 고르는 자동 플레이를 돌린 결과,
입영통지서 비율이 육군 56%, 해병대 64%, 공군 83%였다.
육군 실패 56판을 나눠 보면 탈영 48판, 의병전역 8판이고 지능 미달은 0판이었다.
복무 중 정신력이 바닥나는 게 문제다. 아침 정신력 -2와 NPC 갈구기 -4가 매 사이클 쌓이는 쪽을 먼저 의심하고 3주차에 조정한다.
